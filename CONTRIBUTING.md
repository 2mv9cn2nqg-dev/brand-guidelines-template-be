# Contributing

Contributions are welcome. This is a small project, so keep things simple.

## What helps

- Reporting mistakes in the text or in the legal checklist
- Adding a sector that is missing from the examples
- Writing a French version of the template
- Improving chapters that turn out to be too vague in practice

## How

1. Open an issue first if you want to change something big, so we do not duplicate work.
2. Fork the repository and make one branch per change.
3. Follow the style of the existing chapters: short sentences, fields in `[brackets]`, examples after `> Example:`.
4. Open a pull request with a short note on what you changed and why.

## Legal details

Chapter 7 contains a checklist of Belgian requirements. If you change anything there, include a source, preferably an official page from FOD Economie, the business counter or the legislation itself. Changes without a source cannot be merged.

## Language

The main text is English. The Dutch version is in `nl/`. If you change an English chapter, mention in your pull request whether the Dutch file needs the same change.
